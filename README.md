# KINE 303 Stats Lab

An interactive course for Professor Lawrence's KINE 303 Statistics & Research Methods: learn statistics and Python at the same time, following the weekly class activities. Python runs entirely in the browser (Pyodide); nothing to install, and nothing is sent to a server.

Open the course: https://jacobmayoral7.github.io/kine303-stats-lab/

All datasets are simulated practice data shaped like the class spreadsheets.

This repository only holds the built page. The source (lessons, data generator, tests) lives in `kine303-python-stats/scripts` and is built with `python3 build.py`.
